# User Guide

This folder contains setup, usage, and focused how-to documentation for the opencode-coder plugin.

- [Getting Started](getting-started.md) — install the plugin, run `/opencode-coder/init`, and explicitly enable or configure it for a project
- [Project Setup](project-setup.md) — recommended repository structure and documentation conventions for projects that use the plugin well once enabled
- [Project Doc Guidelines](project-doc-guidelines.md) — what each canonical project doc should contain and how to write it for humans and agents
- [How to Write Commands](how-to-write-commands.md) — contributor reference for keeping commands thin and skill-backed
- [How to Write Skills](how-to-write-skills.md) — contributor reference for runtime-vs-authoring content boundaries
- `docs/OVERVIEW.md` is now included in the recommended structure as the main project overview document
